# 🧮 Scientific Calculator

A modern and responsive Scientific Calculator built with **HTML5, CSS3, and JavaScript**.  
It provides a clean futuristic interface for performing basic arithmetic and scientific mathematical calculations.

## ✨ Features

- ➕ Basic arithmetic operations
- 📐 Trigonometric functions
  - `sin`
  - `cos`
  - `tan`
- 🔢 Mathematical functions
  - Square
  - Square root
  - Powers
  - Logarithm
  - Natural logarithm
- π Mathematical constant
- e Euler's number
- Parentheses support
- Decimal calculations
- Delete functionality
- Clear / Reset functionality
- Responsive calculator layout
- Modern futuristic user interface
- Interactive calculator buttons

## 🛠️ Technologies Used

- **HTML5** — Structure
- **CSS3** — Styling and responsive design
- **JavaScript (ES6+)** — Calculator logic and functionality
